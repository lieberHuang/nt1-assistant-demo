# NT1阵发性睡病助手 · 眠宝功能 Demo

本地 HTML/CSS/JavaScript 原型，无前端构建依赖。疾病名称按用户确认统一为NT1阵发性睡病。

- 在线地址：[打开演示](https://lieberhuang.github.io/nt1-assistant-demo/)
- 本地地址：http://127.0.0.1:8876/
- 源码：[GitHub仓库](https://github.com/lieberHuang/nt1-assistant-demo)

## 当前界面

首页四项功能：创新支付、病程记录、健康科普、联系客服。病历夹和语音病历已融合为病程记录；输入框上方也只保留一个病程记录入口。所有患者操作在同一聊天页面中完成，无二级返回页面。

首页眠宝关怀状态点击即保存，当天刷新保留，次日重新询问。左侧说明可编辑、保存和导出；清空聊天记录不会删除已存病程、用药、福利订单或左侧说明。

## 病程记录

1. 点击病程记录，在聊天中打开统一卡片。
2. **语音记录**：点击进入录入状态，可点击结束，也会自动完成；经过整理状态后，显示“语音记录／时间／总结”三项。语音记录保留原始转写，只读；时间和总结可直接修改。
3. **上传图片**：支持选择多张图片，上传后显示图片及“时间／总结”两项，两个提取字段均可修改。
4. 同一条病程可包含多项语音和图片，每一项保留自己的时间与总结。添加新内容不覆盖已经修改的字段。
5. 确认后整体保存；查看已有记录支持语音／图片筛选、图片原位放大，以及修改原记录，沿用原ID。

**按用户2026-10-16确认，语音和图片提取均只做交互模拟，不调用真实麦克风、STT、OCR或大模型；患者卡片不展示演示标签。** 语音原文和初始提取结果使用预置内容；图片仍真实读取、压缩并存储至当前浏览器。请用演示资料体验。时间／总结可由用户改写，保存后以修改结果为准。

每条病程最多8项内容，其中图片最多4张，单张图片不超过10MB。图片会缩小压缩，损坏文件整批回退。总结不能为空；时间字段允许用户补充。刷新会保留已编辑字段，未结束的模拟录入会恢复为可核对的结果。

旧版文字、图片、文件和语音病历记录保留；查看或编辑时适配到统一结构。旧文件仍能下载，不再提供新的文件或独立语音病历入口。

## 保留功能

- 创新支付：直付与后报销、入组状态、历史订单、材料预览、援助申请和驳回补件。申请中切换功能自动暂停，再次申请先询问是否继续。
- 用药记录：在聊天卡片填写药名、实际时间、用药情况、备注和事实状态，支持修改原记录。
- 科普：聊天推荐列表、完整列表、分类和全文展开。
- 客服：联系卡片及模拟拨号。
- 我的服务：患者档案、会话历史、福利订单。
- 右侧演示场景：切换患者和订单状态；窄窗口可从手机内演示按钮打开。

原需求的状态映射和待确认规则见[业务评审](业务评审.md)。问答、文章、申请、电话与事件均为演示内容，不接入真实诊疗、支付、审批或上报服务。

## 启动与存储

在项目目录运行：

```sh
npm start
```

端口默认8876，也可用`PORT=8877 npm start`。重启电脑后需重新启动本地服务。模拟iPhone 17使用402×874逻辑画布，按窗口等比缩放并居中。

- 会话、患者和订单：当前浏览器localStorage。
- 病程、用药和媒体：当前浏览器IndexedDB（`nt1-care-records-v1`）。
- 本地说明：点击保存后写入`.local/notes.json`，支持刷新和重启服务读取。在线版或直接打开HTML时保存到访问者当前浏览器；说明可以导出文本。
- 清空聊天只清会话；重置演示数据会清理患者演示、会话、病程、用药和媒体，保留说明。
- 不同域名和端口的浏览器数据相互独立，不跨设备同步。清理站点存储会删除浏览器记录。

## 文件与发布

```text
index.html     页面入口
styles.css     手机画布、工作区与卡片样式
app.js         问答、支付、患者服务与演示场景
care.js        业务流程、记录保存和历史兼容
journey.js     统一病程记录、模拟语音／图片处理、字段编辑
workspace.js   说明编辑、保存、导出和画布缩放
server.cjs     本地静态服务及说明保存接口
assets/        眠宝图片
```

```sh
npm run check
```

GitHub Pages从main分支根目录发布，推送后自动部署。`.local/`、原始需求附件和浏览器个人数据不上传。发布包不包含本地说明与Git目录。

眠宝图片来自用户指定的[参考网站](https://lieberhuang.github.io/mianbao-patient-service/)，本地使用`mianbao-lamb.webp`和`mianbao-doctor.webp`。正式使用前由项目方确认素材授权。

验证范围见[验证说明](验证说明.md)。此前固定关怀、草稿列表、音频导入、真实语音识别及五入口等旧行为均已由当前流程替代。
